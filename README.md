# Proyecto Final - Bases de Datos 2

Aplicacion para analizar pruebas especificas de aspirantes
a la Facultad de Ingenieria de la USAC.

## Tecnologias previstas

- Java 21 y Spring Boot
- React con TypeScript
- MongoDB
- Neo4j
- Docker Compose

## Datos

Archivos CSV correspondientes a los anios 2015 a 2024.
